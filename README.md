# A07F02 3D 模型

遠雄洄山行 A07F02 戶 2F 平面圖重建的可旋轉 3D 模型，單一 HTML 檔，以 three.js 繪製。

公開網址：https://oopsdev.github.io/a07f02-3d/

## 功能

- 拖曳旋轉、滾輪或雙指縮放、右鍵或雙指平移，手機可用
- 室內漫遊：「進入室內」從玄關進入，點畫面走過去、拖曳轉頭、方向鍵／WASD 移動，Esc 離開
- 視角：鳥瞰、平面俯視、餐廳看客廳；點地板選空間並顯示長寬
- 設定依區域分組，「目前配置」摘要可展開；設定會記在瀏覽器
- 玄關櫃（前淺後深、後段可看內裝）
- 主臥擺法（IKEA SLATTUM 150 / 180）、床頭櫃、衣櫃
- 餐桌（NORDEN 摺疊桌）平日 2 人 / 宴客 6 人，可放餐廳區或冰箱旁
- 廚房隔間：原始 / 打通（保留冰箱與電器櫃牆）；廚房北牆朝玄關的木作洞洞板
- 臥室一北牆與西牆：實牆 / 腰牆＋上方玻璃（腰牆高度、框型、透明或長虹玻璃）
- 客廳：55 吋電視、BESTÅ 電視櫃、MILSBO 玻璃門櫃、STOCKHOLM 沙發與咖啡桌、木作吊櫃，可互換電視與沙發位置
- 樑：顯示 / 半透明 / 隱藏
- 外牆磚、陽台欄杆與弧形天花板、後陽台設備
- 牆面顏色、陽光方位與高度滑桿、剖切高度、顯示或隱藏文字

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，需要連網（從 jsDelivr 載入 three.js 0.160.0、從 Google Fonts 載入字型）。

## 更新方式

正本是 Google 雲端硬碟裡的 `建物資料/A07F02_3D模型.html`。更新時把它複製成本 repo 的 `index.html`，commit 並 push 到 `main`，GitHub Pages 會自動重新發佈。

## 資料來源與限制

- 牆線取自 Sweet Home 3D 檔與建商尺寸圖，門窗依實品屋照片推算
- 家具尺寸取自 IKEA 台灣官網，價格與庫存以官網為準
- 面積為室內淨面積概算，不是權狀坪數；圖面與現場有 5～8 cm 誤差
- 樑的位置取自客戶單元圖的樑線，圖上沒有樑深；樑底高度為暫定值（離地 270 cm）
