# A07F02 3D 模型

遠雄洄山行 A07F02 戶 2F 平面圖重建的可旋轉 3D 模型，單一 HTML 檔（加上 PWA 用的 manifest、service worker 與圖示），以 three.js 繪製。

公開網址：https://oopsdev.github.io/a07f02-3d/

## 功能

- 拖曳旋轉、滾輪或雙指縮放、右鍵或雙指平移，手機可用
- 室內漫遊：「進入室內」從玄關進入，點一下往那個方向走一步、拖曳轉頭、方向鍵／WASD 移動，Esc 離開；走近門會自動開門，可走到陽台、露台、後陽台
- 視角：鳥瞰、平面俯視、餐廳看客廳；點地板選空間並顯示長寬
- 設定依區域分組，「目前配置」摘要可展開；設定會記在瀏覽器
- 玄關櫃（前淺後深、後段可看內裝）
- 主臥擺法（IKEA SLATTUM 150 / 180）、床頭櫃、衣櫃
- 餐桌（PINNTORP 摺疊桌，松木）平日 2 人（67 cm）/ 宴客 4 人（124 cm），預設靠餐廳北牆，可改放冰箱旁（需廚房打通）；餐桌上方吊 VÄXJÖ 吊燈（原平頂燈出線口不動，出線沿天花板延伸到桌子中線上方的吊點）
- 廚房隔間：原始 / 打通（保留冰箱與電器櫃牆）；廚房北牆朝玄關的木作洞洞板
- 臥室一北牆與西牆：實牆 / 腰牆＋上方玻璃（腰牆高度、框型、透明或長虹玻璃）；改玻璃時北牆整面拆除、下方重做木作腰牆，牆上插座原位重新安裝（彩色＋綠框標示）
- 客廳：55 吋電視、BESTÅ 電視櫃、MILSBO 玻璃門櫃、STOCKHOLM 沙發與咖啡桌、木作吊櫃，可互換電視與沙發位置
- 樑：顯示 / 半透明 / 隱藏
- 外牆磚、陽台欄杆與弧形天花板、後陽台設備；客廳天花板的靜流風機 VAF 與排風管（依客戶單元圖）
- 牆面顏色、陽光方位與高度滑桿、剖切高度、顯示或隱藏文字

## IKEA 3D 模型

`A07F02_ikea_models.js` 收錄 IKEA 官網商品頁公開的 3D 模型（glTF，base64），版權屬於 IKEA，僅供個人規劃參考，不做其他用途；如權利人要求會立即移除。這個檔不存在時，`index.html` 會自動改用簡易方塊家具。

## 修改尺寸

牆、門窗、柱與管道間的尺寸都在 `index.html` 開頭的「平面定義」區塊（`WL`、`OP`、`COL`、`KIT`），依客戶單元圖 PDF 量測。改這裡的數字，房間、靠牆的家具與櫃子、樑、門片都會跟著移，程式不用改。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可（`A07F02_ikea_models.js` 放在同一個資料夾），需要連網（從 jsDelivr 載入 three.js 0.160.0 與 Draco 解壓縮器、從 Google Fonts 載入字型）。

## 加入手機主畫面（PWA）

- Android（Chrome／Edge）：開啟公開網址 → 右上選單 → 「加到主畫面」或「安裝應用程式」
- iPhone／iPad（Safari）：開啟公開網址 → 分享 → 「加入主畫面」
- 加入後以全螢幕開啟；第一次開啟時會把 three.js、字型與 IKEA 模型檔存進快取，之後離線也能開（有網路時一律先抓最新版）
- 圖示由 `icons/icon.svg` 產生（與分頁圖示相同）；重新產生時用 Edge 無頭截圖：`msedge --headless=new --window-size=512,512 --screenshot=icons/icon-512.png file:///.../icon.html`，192 與 180 用 `--force-device-scale-factor` 縮小

## 更新方式

正本是 Google 雲端硬碟裡的 `建物資料/A07F02_3D模型.html`。更新時把它複製成本 repo 的 `index.html`，commit 並 push 到 `main`，GitHub Pages 會自動重新發佈。改 `index.html` 不用動 `sw.js`；改 `sw.js` 或要清掉舊快取時，把裡面 `CACHE` 的版本號加一。

## 資料來源與限制

- 牆、門窗尺寸取自客戶單元圖 PDF（PDF 1 點 = 2.153 cm，以外牆校正）；圖面與現場仍有 5～8 cm 誤差
- 家具尺寸取自 IKEA 台灣官網，價格與庫存以官網為準
- 面積為室內淨面積概算，不是權狀坪數；圖面與現場有 5～8 cm 誤差
- 樑的位置取自客戶單元圖的樑線，圖上沒有樑深；樑底高度為暫定值（離地 270 cm）
- 燈具位置取自客戶單元圖的燈具符號；餐廳吊燈的吊法依電線長度自動選（掛鉤繞線或出線延伸到吊點），電線長度與淨高都要現場確認
